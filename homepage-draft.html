Sammlungen erfassen, verknüpfen und veröffentlichen, ohne sich mit XML-Dateien herumzuschlagen

Katalon ist eine offene Software für Museen, Archive und Sammlungen. Objekte, Personen, Orte und Werke erfassen, mit Normdaten verknüpfen, mit IIIF-Bildern versehen und im eigenen Online-Portal veröffentlichen. Schemata legst du in der Oberfläche fest, nicht in Konfigurationsdateien.

Live-Demo ansehen Quellcode auf GitHub

Warum Katalon

Sammlungen wachsen, Anforderungen ändern sich: neue Objektarten, neue Felder, neue Verknüpfungen. Katalon bildet das direkt in der Oberfläche ab, ohne Konfigurationsdateien und ohne Entwicklerhilfe für jede Anpassung.

  • Neue Felder und Kategorien selbst anlegen, ohne Entwicklerhilfe
  • Bilder direkt im Browser zoomen, ohne separate Software
  • Bestehende Daten aus Excel, CSV oder XML importieren, mit Vorschau vor dem Import

Fünf Bestandstypen, ein System

Jeder Datensatz gehört zu einem von fünf Typen. Welche Felder er trägt, legst du selbst fest.

Objekt
Fotos, Dokumente, Gemälde, digitale Artefakte
Person/Institution
Personen und Organisationen, verknüpft mit Normdaten wie GND
Ort
Geografische Orte mit Kartenanzeige im Portal
Werk/Ereignis
Werke, Ereignisse und Konzepte
Vorgang
Leihverkehr, Erwerbung, Restaurierung

Alle fünf Typen lassen sich beliebig miteinander verknüpfen, jede Verknüpfung kann eigene Angaben tragen, etwa eine Rolle oder ein Datum.

Was Katalon mitbringt

Eigene Felder anlegen

Text, Zahl, Datum, Ort, Vokabular, Normdaten, Verknüpfung, verschachtelte Gruppen. Reihenfolge per Drag-and-Drop, Pflichtfelder und mehrsprachige Beschriftungen frei wählbar.

Verknüpfungen

Jeder Datensatz lässt sich mit jedem anderen verbinden, mit eigenen Angaben zur Beziehung und passender Bezeichnung in beide Richtungen.

Normdaten

Direkter Abgleich mit GND, Geonames, VIAF, Wikidata, Getty TGN und Iconclass. Weitere Quellen lassen sich als Plugin nachrüsten.

Bilder zoomen

Eingebauter IIIF-Bildserver: Objektfotos im Browser bis in Detailschärfe vergrößern, ohne zusätzliche Software.

Suche und Filter

Volltextsuche mit Filtern, die du selbst festlegst. Neue Datensätze sind sofort auffindbar.

Import und Export

Bestehende Daten aus CSV, Excel oder XML übernehmen, mit Vorschau und Fehlerprüfung vor dem eigentlichen Import. Export über OAI-PMH.

Rechte und Rollen

Admin, Bearbeitung, nur Lesen. Jede Änderung an einem Datensatz wird protokolliert und lässt sich nachvollziehen.

Eigenes Erscheinungsbild

Farben, Logo und Institutionsname im Portal anpassen, ohne dass jemand die Software neu bauen muss.

Stand des Projekts

Kernfunktionen sind fertig: Datenmodell, eigene Felder, Rechte und Rollen, Bilder und IIIF, Admin-Oberfläche, Suche, öffentliches Portal, Normdaten, Import und OAI-PMH. In Arbeit: Absicherung für den Produktivbetrieb und eine tiefere Verzahnung verknüpfter Datensätze in der Suche.

Selbst hosten

Katalon läuft über Docker Compose auf eigener Infrastruktur.

git clone https://github.com/karkraeg/katalon.git
cd katalon
docker compose up -d

Setup und Konfiguration: Dokumentation

Für IT-Verantwortliche

Python-Backend (FastAPI), PostgreSQL mit PostGIS, Elasticsearch für die Suche, Cantaloupe als IIIF-Bildserver, React-Oberflächen. Deployment über Docker Compose, läuft auf eigener oder gehosteter Infrastruktur.
